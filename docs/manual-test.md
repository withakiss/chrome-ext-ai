# 수동 테스트 체크리스트

사전: `chrome://extensions` 개발자 모드, `extension/` 로드. 고정 페이지는 `file:///…/test/fixture/search.html`(확장 세부정보에서 "파일 URL에 대한 액세스 허용" 켜기).
자동화 버전: `node test/e2e/run.mjs` — Playwright 캐시의 Chromium을 `--load-extension`으로 띄우고 가짜 LLM 서버로 2번 항목을 외부 접속 없이 검증한다.
